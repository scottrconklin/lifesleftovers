# Approved mockups

These are the approved screen designs, exported from the design canvas. Build each screen to match its file. Read the markup for layout, spacing, colors, copy and component structure. The files use a small templating format (`<x-dc>`, `<sc-for>`, `<sc-if>`, `{{holes}}`) and load a `support.js` that isn't included, so they won't render if opened directly in a browser. Treat them as a precise spec, not as code to copy.
